Why PAN Card Photo Uploads Get Rejected (and How to Fix Each One)

Most rejected uploads come down to one of four things. Here's what each error usually means and the fastest way to fix it.

A PAN application form rarely explains a rejected upload in plain language. In practice, almost every case falls into one of four buckets.

1. Wrong pixel dimensions

The most common cause, and usually not about the photo's shape — it's using the wrong portal's numbers. See our NSDL vs UTI guide to confirm which spec applies to you.

2. File size over the limit

A phone photo is easily several megabytes. Even resized to the right pixel dimensions, an uncompressed image can still be well above the 30-50KB cap most forms enforce — dimensions and file size are two separate checks.

3. Wrong file format

NSDL is strict about JPEG only. A PNG or a HEIC file straight from an iPhone will bounce even with perfect dimensions. UTI is more forgiving, but JPEG is the safer default either way.

4. Background or photo quality

Not always caught automatically — sometimes flagged on manual review instead, which means you find out later. A non-white background, a dark photo, or glare on glasses can lead to a resubmission request even when the file itself was technically valid.

The fastest fix

Start from a well-lit, front-facing photo against a plain background, then let a tool handle the dimension and compression math. Both the UTI and NSDL resizers set the right pixel size automatically and compress toward the file-size limit.
